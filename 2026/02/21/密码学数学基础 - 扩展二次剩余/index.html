密码学数学基础 - 扩展二次剩余

2026-02-21

密码学, 数学, 数论

前一章中，我们主要聚焦于单一素数模数下的二次剩余问题，这为我们理解二次剩余奠定了坚实的基础。然而，在实际应用中，我们经常会遇到更复杂的情况，比如模数是合数或者有多个素因数的情况。在本章中，我们将扩展我们的视野，探讨这些更一般的二次剩余问题。

扩展模数与雅可比符号

当模数为 pk ，其中 p 是奇素数， k≥1 时，我们可以通过扩展勒让德符号来判断一个数是否是模 pk 的二次剩余。对于一个整数 a 和一个奇素数 p ，我们定义：

(apk)=(ap)k

其中 (ap) 是勒让德符号。

雅可比符号可以看作是勒让德符号的推广。对于一个整数 a 和一个正整数 n=p1k1p2k2⋯pmkm ，雅可比符号定义如下：

(an)=∏i=1m(api)ki

雅可比符号具有以下性质：

  1. (an)=(ap1)(ap2)⋯(apm)
  2. (abn)=(an)(bn)
  3. 二次互反律推广：对于两个正整数 m 和 n ，如果 gcd(m,n)=1 ，则 (mn)=(−1)(m−1)2⋅(n−1)2(nm) 。

注意，雅可比符号的值为 −1 并不一定意味着 a 是模 n 的二次非剩余，因为 n 可能不是素数。因此，雅可比符号只能提供一个必要条件，而不是充分条件。

判断扩展模数下的二次剩余

接上文雅可比符号不可以直接用来判断二次剩余，那么欧拉准则在扩展模数下也失效了，设 pk 是一个奇素数的幂，其中 p 是奇素数， k≥1 。对于任意整数 a ，如果 gcd(a,pk)=1 ，则：

apk−12≡(apk)modpk

那么如何判断 a 是否是模 pk 的二次剩余呢？我们有一个结论①：

a 是模 pk 的二次剩余⟺a 是模 p 的二次剩余

也就是说，如果 a 是模 p 的二次剩余，那么它也是模 pk 的二次剩余；反之，如果 a 不是模 p 的二次剩余，那么它也不是模 pk 的二次剩余。
那么实际上我们可以通过判断 a 是否是模 p 的二次剩余来判断 a 是否是模 pk 的二次剩余。

那么对于一个合数 n ，如果 a 是模 n 的二次剩余，那么 a 必须是模 n 的每个素因数的二次剩余。也就是说，如果 n=p1k1p2k2⋯pmkm 是 n 的质因数分解，那么如果 a 是模 n 的二次剩余，则 a 必须是模每个 pi 的二次剩余。因此，我们很容易得到结论：

a 是模 n 的二次剩余⟹a 是模 pi 的二次剩余，对于所有i

求解扩展模数下的二次剩余

之前我们已经知道可以使用Tonelli-Shanks算法来求解模素数的二次剩余，那么对于模为 pk 以及模合数 n 的二次剩余，我们又该如何求解呢？

对于模 pk 的二次剩余，我们有一个结论：如果 a 是模 p 的二次剩余，那么 a 也是模 pk 的二次剩余。我们可以先用Tonelli-Shanks算法求解模 p 的二次剩余，得到一个平方根 x ，然后我们可以通过Hensel-lifting技术进行迭代的方法来求解模 pk 的二次剩余。

对于模合数 n 的二次剩余，我们可以先将 n 分解为其质因数的幂的形式 n=p1k1p2k2⋯pmkm ，然后分别求解模每个 piki 的二次剩余，最后通过中国剩余定理将这些结果组合起来，得到模 n 的二次剩余。

求解一元二次同余方程

我们在求解正常一元二次方程的时候，都是先计算判别式 Δ=b2−4ac ，然后根据判别式的值来判断方程的根的情况，其本质是 Δ 的平方根存在。
那么在模 n 的情况下，我们也可以定义一个类似的判别式来判断一元二次同余方程 ax2+bx+c≡0modp 的解的情况。我们定义判别式 Δ=b2−4ac ，然后用Tonelli-sharks算法计算，根据 Δ 是否存在，即是模 p 的二次剩余来判断方程的解的情况。
然后一样使用韦达定理计算出方程的根

x1≡−b+Δ2amodpx2≡−b−Δ2amodp

当然，一样的模 pk 的情况下要使用 Hensel-lifting 技术进行迭代的方法来求解模 pk 的二次剩余，模合数 n 的情况下要先分解质因数再使用中国剩余定理来组合结果。

Blum 整数和半素数

Blum 整数是指形如 n=p⋅q 的整数，其中 p 和 q 是两个不同的素数，并且满足 p≡3mod4 和 q≡3mod4 。
半素数（又叫二素数）是指形如 n=p⋅q 的合数。

Blum 整数的性质：

  1. 对于 Blum 整数 n ，每个二次剩余都有且仅有四个平方根。
  2. Blum 整数$ \left( \frac{-1}{n} \right) = \left( \frac{-1}{p} \right)\left( \frac{-1}{q} \right) = 1$。
  3. Blum 整数为模数的二次剩余可以直接套用公式来求解平方根②。
x≡a(p−1)(q−1)+48modn

结论①②证明

结论①证明

首先

a∈Zpk∗⟺gcd(a,pk)=1⟺gcd(a,p)=1⟺a∈Zp∗

充分性：
如果 a 是模 pk 的二次剩余，则 a 一定是模 pk 二次剩余集合元素，所以 gcd(a,pk)=1 ，因此 gcd(a,p)=1 。

且$ \exists b \in Z^*_{p^k} $ 使得 a≡b2modpk 。

所以 a≡b2modp ，因此 a∈(Zp∗)2 。

必要性：
如果 a∈(Zp∗)2 ，假设 a 是模 pk 的二次非剩余，那么

aϕ(pk)2≡−1modpkaϕ(pk)2≡−1modpapk−1ϕ(p)2≡−1modpap−12≡−1modp

这与 a∈(Zp∗)2 矛盾，所以 a 是模 pk 的二次剩余。

结论②证明

验证 (p−1)(q−1)+48 是整数

因为 p 和 q 都满足 p≡q≡3mod4 ，设 p=4k+3 ， q=4l+3 ，则

(p−1)(q−1)+48=(4k+2)(4l+2)+48=16kl+16k+16l+88=2kl+2k+2l+1

所以， d=(p−1)(q−1)+48 是一个整数。

模 p 下验证公式

由前面结论，如果 p≡3mod4 ，则 x≡±ap+14modp 。
同理，如果 q≡3mod4 ，则 x≡±aq+14modq 。

我们需要验证 x=admodp 满足 x2≡amodp ：

ad=a(p−1)(q−1)+48=a(p−1)(q−1)8+12=(ap−12)q−14⋅a12

由欧拉判别法， ap−12≡1modp ，因此：

ad≡1q−14⋅a12≡a12modp

又因为 q≡3mod4 ， q−14 是整数，且 a12=ap+14modp （即素数模下的平方根），所以：

(ad)2≡amodp

同理可证，在模 q 下也有 (ad)2≡amodq 。

CRT 合成验证

由 CRT，若 x2≡amodp 且 x2≡amodq ，则存在唯一的 xmodn 满足 x2≡amodn 。

而 admodn 同时满足模 p 和模 q 的平方根条件，因此它就是模 n 下的一个平方根。
